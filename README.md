## 🌿 About the Project
This is the official web showcase for **Garg Handloom Home Decor**, located in the Main Market Area, Palwal, Haryana. 

Designed with modern **Light-Aesthetic Glassmorphism 2.0**, fresh sun-drenched architectural imagery, and an interactive fabric visualizer.

### Key Highlights:
- **Fresh Light Luxury Aesthetic**: Clean alabaster, soft linen tones, frosted glass panels (`backdrop-filter: blur(24px)`).
- **Interactive Fabric Studio**: Real-time drape and sunlight simulation across signature fabric tones.
- **Extreme Local SEO Suite**:
  - `HomeGoodsStore` / `LocalBusiness` JSON-LD schema with exact geo-coordinates, hours, and phone number.
  - `FAQPage` schema for Google search rich snippets.
  - Comprehensive metadata, OpenGraph tags, `robots.txt`, and `sitemap.xml`.
- **Verified Reviews & Showroom Integration**: Direct 1-tap Google reviews and Google Maps navigation.
- **Mobile-First Floating Action Dock**: One-tap access to Directions, Phone, WhatsApp, and Google Reviews.
